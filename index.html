Linux Workstation Tuning

How I Turned Linux Into My Ultimate Productivity Machine

By Akshat Soni • 5 min read • GNOME + ZRAM Blueprint

I wanted my Linux desktop to feel clean, fast, and polished enough that I wouldn't miss the little things I liked about macOS — while still keeping the flexibility and control that Linux gives me.

The result is a minimal GNOME desktop with a macOS-inspired look, a floating dock, a clean top bar, smart window tiling, smooth animations, and a few memory tweaks that make the system feel responsive even when I'm doing a lot at once.

Whenever friends or colleagues who daily-drive a MacBook sit down at my desk, their first comment is almost always: "Wait... why does this feel snappier than my Mac?"

The important part: you don't need to understand every obscure GNOME setting to reproduce it.

I've put the entire desktop configuration into a simple setup script, so most of the customization is just running two commands:

Bash 
chmod +x ~/setup.sh
~/setup.sh

If you're new to Linux, think of setup.sh as a little installer that tells Linux which settings to change for you.

What the setup actually changes

1. A cleaner GNOME desktop

I use GNOME as the base because it is simple and distraction-free. I changed the appearance to a dark, macOS-inspired setup with:

  • WhiteSur-style theme: Clean dark visual language.
  • modern-repack icons: Dark mode icons with crisp application recognition.
  • SF Pro & JetBrains Mono typography: Clean legibility across all windows.
  • Text Scaling at 1.2: Comfortable reading on modern 1080p/2K/4K displays.
  • Dark Monterey wallpaper: Abstract depth without visual noise.
  • Minimal window controls: Clean :minimize,maximize,close layout.

2. A floating dock

Instead of having a large permanent panel at the bottom, I use a small floating dock with Dash to Dock. It stays out of the way until I need it, while still giving me quick access to frequently used applications.

The dock also shows running applications with small dot indicators, so I can immediately see what's open, and clicking an app automatically minimizes or cycles windows.

3. A useful top bar

I wanted the top bar to show information that I actually care about instead of filling it with random indicators. Mine includes:

  • Apps & Places menus: Fast, discreet drop-downs instead of full-screen search interruptions.
  • RAM & Swap usage: Real-time graphs so I always know system headroom.
  • A centered date/time: Clean numeric format.
  • Transparent appearance: Blends into the wallpaper seamlessly via dynamic-transparent-top-bar.

4. Better window management

This is probably the biggest productivity improvement. I use Tiling Shell to quickly arrange windows.

Instead of manually resizing windows, I can snap them into layouts and keep everything organized. I also use very small gaps between windows — just 4px — so the desktop stays clean without wasting screen space.

5. Smoother animations (The Genie Effect)

I like having animations, but they shouldn't slow me down. The setup uses Compiz Alike Magic Lamp Effect to give minimized windows a smooth genie-style swoop into the dock:

Making Linux handle memory better

This is the part that's useful even if you don't care about the visual customization. I use ZRAM.

What is ZRAM?

Normally, when Linux runs low on RAM, it moves memory pages out to your SSD. That works, but disk storage is thousands of times slower than RAM, leading to sluggishness and system freezes.

ZRAM takes a different approach: it creates a compressed block of memory inside RAM and stores less-active memory pages there in compressed form using lz4. Instead of immediately pushing everything to the disk, Linux keeps more of the workload compressed in RAM.

Ubuntu / Debian Installation

Terminal 
sudo apt update && sudo apt install zram-tools

Edit /etc/default/zramswap:

/etc/default/zramswap 
ALGO=lz4
PERCENT=50
PRIORITY=100

Restart with sudo systemctl restart zramswap.

Fedora Setup

Fedora uses systemd-zram-generator:

Terminal 
sudo dnf install zram-generator

In /etc/systemd/zram-generator.conf:

/etc/systemd/zram-generator.conf 
[zram0]
zram-size = ram / 2
compression-algorithm = lz4

One small swap adjustment (vm.swappiness = 25)

I also set Linux's swappiness to 25. This doesn't mean "never use swap" — it simply makes the kernel less eager to dump active application caches when plenty of RAM is still free.

Terminal 
echo "vm.swappiness=25" | sudo tee /etc/sysctl.d/99-swappiness.conf
sudo sysctl --system

Why I like this setup

The goal wasn't to make Linux look like macOS for the sake of imitation.

It was to take some of the things I like about modern desktop operating systems — clean visuals, predictable window management, smooth animations, and useful information — and combine them with the freedom and raw speed of Linux.

Less time managing the desktop, more time actually using it.
